Privacy policy

gdirect Personal Drive · maintained by WfrRadio · effective October 27, 2026.

Data accessed and its purpose

This personal desktop configuration accesses the Google account identifier and Google Drive file metadata and contents necessary for the owner's requested browsing, downloads, uploads, editing and filesystem mount operations. The full Drive scope permits access to existing files and changes requested by the owner. No advertising, profiling or AI model training is performed by this configuration.

Local storage and retention

OAuth client information, access and refresh tokens, folder metadata, transfer state and mount caches are stored locally by gdirect and rclone. Credentials are stored with restrictive file permissions. Cached files or pending uploads may remain after unmounting. This static website has no application backend and does not receive these credentials, metadata or file contents.

Sharing and network transport

The desktop application sends requests and user-selected file data to Google Drive. This installation routes its mount connections through the third-party TCP relay 183.56.143.147 while retaining end-to-end HTTPS and certificate verification. The relay operator can observe the connecting IP address, timing, traffic volume and possibly Google hostnames. The configuration does not intentionally disclose plaintext tokens or file contents to the relay, and its operator's independent metadata retention is not controlled by WfrRadio.

Google processes data under its own policies. GitHub hosts this static site and may process ordinary website access logs under its own privacy policy. No additional analytics or tracking scripts are installed on this site. Google user data is not sold, used for advertising or shared with data brokers.

Google API Limited Use

gdirect Personal Drive's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Control and deletion

The owner can stop the mount, sign out with gdirect, and revoke access in Google Account permissions. Revoking authorization stops future authorized access but does not remove files already downloaded or cached locally. The owner can remove local credentials and cached data when no pending upload needs to be preserved. Cloud files remain in Google Drive unless the owner changes or deletes them.

Contact

Questions about this configuration may be submitted to WfrRadio's website issue tracker. Do not post credentials, tokens or private file contents in public issues.
