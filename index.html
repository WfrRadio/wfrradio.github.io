gdirect Personal Drive

A personal desktop configuration maintained by WfrRadio for browsing, downloading, uploading and mounting the owner's Google Drive on macOS.

This is an independently maintained personal configuration of the open-source gdirect project. It is not a Google product and is not operated by gdirect's upstream author.

What it does

The desktop application signs in through Google's OAuth consent screen. It lets the account owner access existing Drive files and folders, download files, upload local files, and use a local filesystem mount to save changes. This static website provides application information only; it does not sign users in or receive Google credentials.

Why Google Drive access is requested

The application requests the Google Drive scope (https://www.googleapis.com/auth/drive) to list and read existing files, create and upload files, and edit, rename, move or delete files when the owner performs those actions. It is intended for the owner's personal use, not as a public cloud storage service.

Where data goes

Credentials and file caches are stored on the owner's computer. Drive requests are sent to Google. The configured network path uses a third-party TCP relay at 183.56.143.147, with HTTPS certificate verification retained. The relay can observe connection metadata but is not given plaintext credentials or file contents by this configuration.

Read the privacy policy and terms of use before granting access. Access can be revoked at any time in Google Account permissions.
